# Unofficial Majora's Mask N64 Guide

An original, spoiler-full 100% walkthrough for the Nintendo 64 version of *The Legend of Zelda: Majora's Mask*.

- Separate Markdown file and URL for every main chapter, side quest, and mask quest
- 52 Heart Pieces, 6 Bottles, upgrades, songs, and Stray Fairy references
- Mobile-first navigation and browser-local checklist progress
- No ads, analytics, database, paid API, or server

## Hosting cost

The site is static and publishes from the `docs/` directory with GitHub Pages. Public-repository Pages is included with GitHub Free. The project contains no paid service integration, custom domain, analytics, database, API, or server.

One-time repository setting: **Settings → Pages → Deploy from a branch → `main` / `docs`**. Every later push to `main` republishes the site automatically.

## Local preview

GitHub Pages builds the `docs/` directory with Jekyll. If Ruby and Bundler are installed:

```bash
bundle install
bundle exec jekyll serve --source docs
```

Content can also be read directly as Markdown without building the site.
