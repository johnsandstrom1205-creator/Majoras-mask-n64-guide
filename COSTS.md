# Cost profile

This repository is designed to have **0 SEK in ongoing hosting cost**.

| Component | Choice | Cost |
|---|---|---:|
| Source repository | Public GitHub repository | 0 SEK on GitHub Free |
| Web hosting | GitHub Pages from `main/docs` | 0 SEK for a public repository |
| Site generation | GitHub's built-in Jekyll build | 0 SEK |
| Database | None | 0 SEK |
| Server/API | None | 0 SEK |
| Analytics/ads | None | 0 SEK |
| Checklist storage | Browser `localStorage` on the reader's device | 0 SEK |
| Domain | Default `github.io` address | 0 SEK |

No payment card, cloud account, usage-priced API, or custom domain is required. A custom domain is intentionally not configured because buying a domain would be an optional external cost.
