All walkthrough prose in this project was written from scratch. The following public references were used to cross-check counts, schedules, N64/3DS differences, and item locations:

- [Nintendo — official game and series information](https://www.nintendo.com/)
- [Zelda Dungeon — Majora's Mask walkthrough index](https://www.zeldadungeon.net/majoras-mask-walkthrough/)
- [Zelda Dungeon Wiki — N64 Stray Fairies](https://www.zeldadungeon.net/wiki/Majora%27s_Mask_Stray_Fairies)
- [StrategyWiki — Majora's Mask reference](https://strategywiki.org/wiki/The_Legend_of_Zelda:_Majora%27s_Mask)
- [Thonky — Pieces of Heart and Bombers' Notebook references](https://www.thonky.com/zelda-majoras-mask/)

No text, screenshots, maps, logos, sprites, scans, or artwork from those sources are reproduced here. This is an unofficial fan project and is not endorsed by Nintendo.
