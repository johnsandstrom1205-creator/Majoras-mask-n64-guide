## Route

1. Return Clock Town's single fairy as Deku Link in the opening cycle for magic.
2. Return it as human Link after resetting for the Great Fairy's Mask.
3. Collect 15 fairies in Woodfall for the enhanced spin attack.
4. Collect 15 in Snowhead for Double Magic.
5. Collect 15 in Great Bay for Double Defense.
6. Collect 15 in Stone Tower for the Great Fairy's Sword.

> **Cycle note:** Temple fairies reset if time is rewound. Return all 15 to the correct regional fountain before playing the Song of Time.
