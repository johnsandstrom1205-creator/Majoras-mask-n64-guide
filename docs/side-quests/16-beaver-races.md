## Route

1. Hookshot up the palm trees beside Zora Cape's waterfall.
2. Swim through all 20 rings before time expires.
3. Beat the brother's 25-ring course.
4. Challenge both again and win the harder rematch for the heart piece.

> **Cycle note:** Pass through every ring in order. Hold the fast-swim input and break jars with the barrier when you need magic.
