## Route

1. Find the four grottos containing a large Gossip Stone.
2. At each, play the same regional song: Sonata of Awakening, Goron Lullaby, or New Wave Bossa Nova.
3. Make all four large stones the same color.

> **Cycle note:** The choice of song does not matter, but the same song must be used at all four stones in the same cycle.
